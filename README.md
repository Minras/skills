# Agent Skills

This repository contains reusable AI agent skills for software development and agentic workflows. Skills follow the Agent Skills convention and are organized in individual directories, each containing a `SKILL.md` file.

## Available skills

| Skill | Description | Instructions |
| --- | --- | --- |
| `implement-user-stories` | Implement repository user stories from clear acceptance criteria, with clarification and independent review when needed. | [SKILL.md](skills/implement-user-stories/SKILL.md) |

## Installation and usage

For a compatible AI coding agent, add the skill directory to the agent's configured skills location, preserving its `SKILL.md` file. Alternatively, use the agent's documented method for importing or registering local skills. Installation paths and activation steps vary by agent; consult its documentation, then invoke `implement-user-stories` when working on a user story.
